# CH03 - Operators and Expressions

This chapter teaches PHP operators through executable PHP files.

The goal is not only to read the syntax, but also to run each file in the browser and observe the output.

## How to Run

1. Put the `PHP` folder inside your XAMPP `htdocs` folder.
2. Start Apache in XAMPP Control Panel.
3. Open the chapter files through `localhost`.

Example:

```text
http://localhost/PHP/CH03%20-%20Operators%20and%20Expressions/01%20-%20Arithmetic%20Operators.php
```

## Chapter Files

| File | Topic | Main Purpose |
|---|---|---|
| `01 - Arithmetic Operators.php` | Arithmetic operators | Learn `+`, `-`, `*`, `/`, `%`, and `**`. |
| `02 - Assignment Operators.php` | Assignment operators | Learn `=`, `+=`, `-=`, `*=`, `/=`, `%=`, and `**=`. |
| `03 - Comparison Operators.php` | Comparison operators | Learn equality, identity, inequality, greater than, less than, and spaceship comparison. |
| `04 - Logical Operators.php` | Logical operators | Learn `&&`, `||`, and `!` for combining conditions. |
| `05 - String Operators.php` | String operators | Learn string concatenation using `.` and `.=`. |
| `06 - Increment and Decrement.php` | Increment and decrement | Learn `++$x`, `$x++`, `--$x`, and `$x--`. |
| `07 - Ternary Operator.php` | Ternary and null coalescing | Learn compact conditional assignment using `? :` and `??`. |

## Important Notes

- Operators are symbols that perform actions on values.
- Expressions are pieces of code that produce a result.
- PHP supports arithmetic, assignment, comparison, logical, string, and conditional operators.
- For comparison, `===` is usually safer than `==` because it checks both value and data type.
- For database and form handling later, operators are very important because they are used in validation and conditions.
