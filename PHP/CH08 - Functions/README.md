# CH08 - Functions

This chapter teaches PHP functions using executable PHP files.

Functions are very important in backend development because they allow us to reuse code. Instead of writing the same logic again and again, we can put the logic inside a function and call it whenever we need it.

## Files in This Chapter

| No. | File | Main Concept |
|---|---|---|
| 01 | 01 - Basic Function.php | Create and call a simple function |
| 02 | 02 - Function Parameters.php | Pass values into a function |
| 03 | 03 - Return Value.php | Return a result from a function |
| 04 | 04 - Default Parameter Value.php | Use default values when arguments are not given |
| 05 | 05 - Type Declaration.php | Control parameter and return data types |
| 06 | 06 - Variable Scope.php | Understand local, global, and static variables |
| 07 | 07 - Reusable Helper Function.php | Create helper functions for repeated backend tasks |

## How to Run

1. Put the `PHP` folder inside the XAMPP `htdocs` folder.
2. Start Apache from XAMPP Control Panel.
3. Open the file using `localhost`.

Example path:

```text
http://localhost/PHP/CH08%20-%20Functions/01%20-%20Basic%20Function.php
```

## Important Notes

- A function is created using the `function` keyword.
- A function does not run automatically after being created.
- A function only runs when it is called.
- Parameters allow a function to receive values.
- `return` allows a function to send a value back to the caller.
- Helper functions are commonly used in PHP backend projects.
