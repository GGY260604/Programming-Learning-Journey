# CH07 - Arrays

This chapter teaches PHP arrays using executable PHP files.

Arrays are very important in PHP because backend data is often handled as a collection of values. For example, a list of students, a list of menu items, a list of orders, or a database result can all be represented using arrays.

## Files in This Chapter

| No. | File | Main Concept |
|---|---|---|
| 01 | 01 - Indexed Array.php | Store values using numeric indexes |
| 02 | 02 - Associative Array.php | Store values using named keys |
| 03 | 03 - Multidimensional Array.php | Store arrays inside another array |
| 04 | 04 - Array Looping.php | Loop through arrays using `for` and `foreach` |
| 05 | 05 - Common Array Functions.php | Use common array functions such as `count()`, `array_push()`, `sort()`, and `in_array()` |
| 06 | 06 - Array to HTML Table.php | Display array data inside an HTML table |

## How to Run

1. Put the `PHP` folder inside the XAMPP `htdocs` folder.
2. Start Apache from XAMPP Control Panel.
3. Open the file using `localhost`.

Example path:

```text
http://localhost/PHP/CH07%20-%20Arrays/01%20-%20Indexed%20Array.php
```

## Important Notes

- Indexed arrays use number indexes such as `0`, `1`, and `2`.
- Associative arrays use named keys such as `name`, `email`, and `age`.
- Multidimensional arrays are useful when handling records, such as many students.
- `foreach` is usually the most convenient loop for arrays.
- Database result rows are commonly handled as associative arrays in PHP.
