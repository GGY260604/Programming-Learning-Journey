# 🌐 HTML Learning Journey

This repository documents a complete beginner-to-intermediate journey of learning **HTML**, **CSS**, and **JavaScript** step by step.

The goal of this tutorial is not just theory — every concept is taught through **executable `.html` files**, with clear comments explaining what each line of code does.

---

# 📚 What You Will Learn

This tutorial is structured into chapters (CH01 – CH11), where:

- Each **folder = one topic**
- Each **file = one executable lesson**
- Each file contains:
  - Working HTML code
  - Inline explanations using comments
  - Visual demonstrations
