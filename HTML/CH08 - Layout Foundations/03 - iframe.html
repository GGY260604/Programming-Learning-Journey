CH08 - iframe

The <iframe> tag is used to embed another webpage inside your page.

1) Basic iframe Example

2) YouTube Embed Example

Important Attributes

  • src = URL to embed
  • width = width of iframe
  • height = height of iframe
  • allowfullscreen = allow full screen mode

⚠ Some websites block iframe embedding for security reasons.

Modern sites often use security headers to prevent embedding.

Common Mistakes

  • Using normal YouTube URL instead of embed URL
  • Forgetting width and height
  • Trying to embed websites that block iframe

Mini Practice

  1. Embed a YouTube video of your choice.
  2. Change width to 600 and height to 300.
  3. Try embedding a website and observe if it works.
