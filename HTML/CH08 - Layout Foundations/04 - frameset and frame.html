CH08 - frameset and frame

The <frameset> and <frame> tags were used in old HTML to split the browser window into separate sections.

What is frameset?

A <frameset> was used to divide the browser window into multiple frames.

30% left frame
70% right frame
A frameset page did not use a normal <body> tag.

Basic frameset Syntax:

<frameset cols="30%, 70%">
  <frame src="menu.html" name="menuFrame">
  <frame src="content.html" name="contentFrame">
</frameset>

This creates two vertical sections: one small frame and one larger frame.

rows and cols:

Use cols to split the window into columns. 

<frameset cols="25%, 75%">
  <frame src="left.html">
  <frame src="right.html">
</frameset>

Use rows to split the window into rows. 

<frameset rows="20%, 80%">
  <frame src="top.html">
  <frame src="bottom.html">
</frameset>

Important Attributes:

  • cols = split the window into vertical columns
  • rows = split the window into horizontal rows
  • src = file loaded inside the frame
  • name = frame name, useful for targeting links

Important: <frameset> and <frame> are obsolete in HTML5.

For modern HTML, use <iframe> when you need to embed another page inside your page.

Common Mistakes:

  • Using frameset and frame in modern HTML5 websites
  • Putting <frameset> inside a normal <body>
  • Forgetting that each <frame> loads a separate page
  • Confusing <frame> with <iframe>
