CH02 - Paragraph and Line Break

In HTML, text is organized using: <p> for paragraphs and <br> for line breaks.

Paragraph (<p>) Demo:

This is the first paragraph.

This is the second paragraph.

Even if you press Enter many times in your code, the browser ignores extra spaces.

Notice: Each <p> automatically creates vertical spacing before and after it.

Line Break (<br>) Demo:

This is line one.
This is line two (after br).
This is line three.

Important: - <br> does NOT create a new paragraph. - It only moves content to the next line.

Difference Between <p> and <br>:

  • <p> = a block of text (new section)
  • <br> = just move to next line
  • Use <p> for proper structure
  • Use <br> only when necessary (like poetry or addresses)

Common Mistakes:

  • Using many <br> to create spacing (wrong way)
  • Forgetting to close <p> tag
  • Thinking pressing Enter in code creates line breaks (it doesn't)

Mini Practice:

  1. Create three separate paragraphs about yourself.
  2. Write your home address using <br> to break lines.
  3. Try removing <br> and observe what happens.
