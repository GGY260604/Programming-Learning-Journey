CH02 - Superscript, Subscript and Small

These tags are used for specific text formatting purposes in HTML.

Superscript (<sup>):

23 = 8

This is a footnote example1.

Superscript raises text slightly above normal line height.

Subscript (<sub>):

Water formula: H2O

Carbon dioxide: CO2

Subscript lowers text slightly below the normal line.

Small Text (<small>):

This is normal text.

This is smaller text using small tag.

is often used for disclaimers or secondary information.

Combined Example:

E = mc2

Price: $100 (excluding tax)

Common Mistakes:

  • Using <sup> or <sub> for styling instead of meaning
  • Overusing <small> for layout spacing
  • Forgetting to close the tags properly
