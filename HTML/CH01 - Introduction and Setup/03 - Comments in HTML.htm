CH01 - Comments in HTML

HTML comments are used to write notes inside your code. They are NOT visible in the browser.

Comment Syntax:

<!-- This is a comment -->

Live Demo:

This paragraph is visible in the browser.

Try deleting the comment symbols around the hidden paragraph, then save and refresh to see what happens.

Why Use Comments?

  • Explain your code for future you
  • Organize large sections clearly
  • Temporarily disable code for testing
  • Improve readability for teamwork

Professional Usage Example:

<!-- =========================
     Navigation Section
     ========================= -->

<!-- Main Heading -->
<h1>My Website</h1>

Common Mistakes:

  • Forgetting to close a comment with -->
  • Trying to nest comments (HTML does NOT support nested comments)
  • Thinking comments are secure (they can still be seen in page source)

Mini Practice:

  1. Add a comment above the heading explaining what this page is about.
  2. Comment out the visible paragraph and refresh.
  3. Uncomment it again.
