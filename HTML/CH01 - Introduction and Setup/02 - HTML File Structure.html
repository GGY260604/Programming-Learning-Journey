CH01 - HTML File Structure

Every HTML file follows this basic structure: 

<!DOCTYPE html> 
<html>
  <head>
    (meta information)
  </head>

  <body>
    (visible content)
  </body>
</html>

1) <!DOCTYPE html>

Tells the browser this is an HTML5 document. Always put it at the top.

2) <html> ... </html>

The root element of the page. Everything must be inside this tag.

3) <head> ... </head>

Contains metadata (information about the page). Example: title, encoding, linked CSS files. Content here is NOT visible on the page.

4) <body> ... </body>

Contains everything visible to the user: text, images, buttons, forms, etc.

Common Mistakes:

  • Forgetting <!DOCTYPE html>
  • Putting visible content inside <head>
  • Forgetting to close tags properly
  • Nesting tags incorrectly
