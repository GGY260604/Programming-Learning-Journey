CH09 - Custom data-* Attributes

HTML allows custom attributes that start with data-. These are commonly used with JavaScript.

Explanation

  • data-product-id = custom data
  • data-product-name = custom data
  • data-price = custom data

These attributes do nothing by themselves. They are mainly used by JavaScript.

Interactive Demo

Important Notes

  • Must start with data-
  • Used for storing custom data
  • Accessed in JS via element.dataset.name
  • Common in modern web development

Common Mistakes

  • Forgetting "data-" prefix
  • Using uppercase letters (not recommended)
  • Confusing data attributes with id or class

Mini Practice

  1. Add a button with data-score="95".
  2. Modify JavaScript to display that score.
