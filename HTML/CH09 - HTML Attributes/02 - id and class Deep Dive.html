CH09 - id vs class Deep Dive

1) id (Unique)

This div has id="uniqueBox"

You cannot have another element with the same id.

2) class (Reusable)

First div with class="groupBox"
Second div with same class
Third div with same class

3) Multiple Classes

This div has multiple classes.

Comparison

  • id = Unique, one per page
  • class = Reusable, many per page
  • id is stronger/more specific in CSS
  • class is preferred for styling multiple elements

Best Practices

  • Use id for unique elements (like main container)
  • Use class for styling groups
  • Do NOT reuse the same id
  • Avoid overusing id for styling

Common Mistakes

  • Using same id multiple times
  • Using id when class is more appropriate
  • Confusing id and name attribute

Mini Practice

  2. Create one unique header using id.
