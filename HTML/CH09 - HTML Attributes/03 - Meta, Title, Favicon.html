CH09 - Meta, Title and Favicon

1) Title

The <title> tag defines the browser tab name. It is NOT visible inside the page.

2) Meta Tags

  • charset → text encoding
  • viewport → mobile scaling
  • description → search engine preview
  • keywords → page keywords
  • author → page author

3) Favicon

Favicon is the small icon shown in browser tab. It is linked using: <link rel="icon" href="favicon.ico">

SEO Basics

  • Always include meaningful title
  • Write clear meta description
  • Use semantic HTML
  • Use proper headings hierarchy

Common Mistakes

  • Missing viewport meta (bad mobile display)
  • Duplicate title across pages
  • Wrong favicon path
  • Overstuffing keywords

Mini Practice

  1. Change the page title and observe browser tab.
  2. Add your name to author meta.
  3. Create a small favicon and link it.
  4. Inspect page source (Right Click → View Page Source).
