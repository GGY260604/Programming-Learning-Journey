What is CSS?

  • CSS = Cascading Style Sheets
  • Controls how HTML looks
  • Handles colors, layout, spacing, fonts
  • Keeps design separate from structure

Structure vs Style

HTML = Structure (Skeleton)

CSS = Style (Clothes & Design)

Why Separation Matters

  • Cleaner code
  • Easier maintenance
  • Reusable styles
  • Professional web development standard
