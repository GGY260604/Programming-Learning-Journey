CH10 - CSS Box Model

Content Area

What is the Box Model?

Every HTML element is treated as a rectangular box.

  • Content → The actual text/image
  • Padding → Space inside the box
  • Border → Edge around padding
  • Margin → Space outside the box

Structure Order

From inside to outside:

  1. Content
  2. Padding
  3. Border
  4. Margin

Important Concept

Total width of element =

width + padding + border

(Margin is outside this calculation.)

Mini Practice

  1. Increase padding to 40px.
  2. Change margin to 5px.
  3. Change border thickness.
  4. Remove margin and see the difference.
