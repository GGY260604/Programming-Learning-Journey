First JavaScript Example

Where Does JavaScript Run?

JavaScript runs inside the browser using a built-in engine.

  • Chrome → V8 Engine
  • Firefox → SpiderMonkey
  • Edge → Chakra (older) / V8 (modern)

Important Concept

JavaScript can:

  • Change HTML content
  • Change CSS styles
  • Respond to user actions
  • Validate forms
  • Communicate with servers
