CH11 - Internal JavaScript

Original Title

Explanation

  • document.getElementById() selects HTML element
  • addEventListener() listens for events
  • JavaScript runs after page loads

Why Internal JS Is Better Than Inline

  • Keeps HTML clean
  • Easier to maintain
  • More professional
