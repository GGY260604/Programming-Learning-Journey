CH04 - Ordered List (ol)

An ordered list uses <ol>. Items are automatically numbered.

Basic Ordered List:

  1. Wake up
  2. Brush teeth
  3. Go to school
  4. Study HTML
Use <ol> when order matters.

Different Numbering Types:

  1. Item A
  2. Item B
  1. Item a
  2. Item b
  1. Item I
  2. Item II

Start Number:

  1. Step Five
  2. Step Six

Reversed List:

  1. Third
  2. Second
  3. First

Nested Ordered List:

  1. Frontend
    1. HTML
    2. CSS
  2. Backend
    1. Node.js
    2. Python

Common Mistakes:

  • Using <ol> when order doesn't matter
  • Putting text directly inside <ol> without <li>
  • Incorrect nesting outside <li>

Mini Practice:

  1. Create a step-by-step recipe using ordered list.
  2. Start numbering from 10.
  3. Create a reversed countdown list.
  4. Make a nested ordered list for subjects and topics.
