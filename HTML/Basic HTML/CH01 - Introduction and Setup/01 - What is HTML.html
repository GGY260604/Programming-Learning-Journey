This file demonstrates: HTML = page structure + content

Tip: Open this file in your editor and browser side-by-side. Change text, save, refresh.

HTML: builds the content and structure (text, headings, buttons, forms).

CSS: controls how it looks (colors, layout, spacing).

JavaScript: controls behavior (click actions, dynamic updates).

Demo: HTML is structure

My First Structured Content

This is a paragraph. HTML tags tell the browser what this text means. It's not about styling yet — it's about structure.

Here is a bullet list (unordered list):

  • HTML = structure
  • CSS = style
  • JavaScript = behavior

Notes / Common Mistakes:

  • Most tags come in pairs: <p>...</p>
  • Spacing inside tag brackets breaks it: < h1 > is wrong.
  • HTML is about meaning: headings, paragraphs, lists, forms.
