CH10 - Inline CSS

Inline CSS means writing CSS directly inside an HTML element using the style attribute.

Basic Example

This text is red using inline CSS.

This paragraph has multiple inline styles.

How It Works

  • style attribute contains CSS rules
  • Each rule: property: value;
  • Multiple rules separated by semicolon

Advantages

  • Quick testing
  • Small one-time styling
  • Email HTML sometimes requires inline CSS

Disadvantages

  • Messy code
  • Hard to maintain
  • Not reusable
  • Mixes structure and style

Inline CSS has the highest priority in CSS. (We will learn about priority later.)

Mini Practice

  1. Change button background to green.
  2. Add font-size: 20px; to one paragraph.
  3. Add border: 2px solid black; to a heading.
