CH05 - Table Basics

Tables are used to display structured data in rows and columns.

Basic Structure:

Name Age Course
Alex 20 Computer Science
Maria 21 Software Engineering
  • <table> = container for table
  • <tr> = table row
  • <th> = header cell (bold + centered by default)
  • <td> = normal data cell

Important Notes:

  • Each row is wrapped inside <tr>
  • Header row usually goes first
  • Number of <td> must match header count
  • Tables are for data, NOT for layout

Common Mistakes:

  • Forgetting to close <tr>
  • Uneven number of <td>
  • Using table for page layout (bad practice)

Mini Practice:

  1. Create a table of 3 products with price and stock.
  2. Add at least 4 rows.
  3. Try adding one extra <td> and observe structure issue.
