CH05 - thead, tbody, tfoot

Professional tables are divided into sections: <thead>, <tbody>, <tfoot>.

Structured Table Example:

Product Price Quantity
Laptop $1000 2
Mouse $25 5
Total Items 7
  • thead = header content
  • tbody = main data
  • tfoot = summary / total
  • Improves readability and organization
  • Helps screen readers and accessibility
  • Useful for large tables with scrolling

Important Notes:

  • These tags are semantic (meaning-based)
  • They do NOT change layout by default
  • Order in HTML5 can be flexible (tfoot can appear before tbody)
  • Use them in real projects for clean structure

Common Mistakes:

  • Putting header rows inside tbody
  • Forgetting to close sections properly
  • Using tables for page layout

Mini Practice:

  1. Create a student score table using all three sections.
  2. Add a footer row showing average score.
  3. Use colspan inside tfoot.
