CH05 - Rowspan and Colspan

Sometimes we want to merge cells in a table. That's where colspan and rowspan are used.

Colspan (Merge Columns):

Name Contact Info
Alex Email Phone

colspan="2" merges two columns into one cell.

Rowspan (Merge Rows):

Day Subject
Monday Math
Science

rowspan="2" merges two rows vertically.

Combined Rowspan and Colspan:

Name Scores
Math Science
Maria 90 95
  • colspan = horizontal merge
  • rowspan = vertical merge
  • You must adjust other cells accordingly
  • Incorrect spanning breaks table structure

Common Mistakes:

  • Forgetting to remove extra <td> when using colspan
  • Miscounting total columns
  • Creating uneven row structure

Mini Practice:

  1. Create a timetable using rowspan.
  2. Create a header that spans 3 columns.
  3. Combine both rowspan and colspan.
