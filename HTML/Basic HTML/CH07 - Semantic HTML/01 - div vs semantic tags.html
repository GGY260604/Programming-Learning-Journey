CH07 - Semantic HTML

Semantic means: tags that describe the meaning of the content.

Non-Semantic Layout (using div only):

div (header area)

This could be a header, but the tag doesn't say so.

div (main content)

This could be the main page content.

div (footer area)

This could be a footer, but the tag doesn't say so.

Semantic Layout (recommended):

header

Top area: logo, title, navigation

main

Main content of the page (usually only one main per page)

footer

Bottom area: copyright, links, contact

Common Semantic Tags:

<header> — page/section header
<nav> — navigation links
<main> — main content
<section> — a section of content
<article> — an independent article/post
<aside> — side content (sidebar, notes)
<footer> — footer area

Common Mistakes:

  • Using only <div> everywhere even when semantic tags fit
  • Using multiple <main> tags (usually only one per page)
  • Thinking semantic tags change style (they don't — CSS does)

Mini Practice:

  1. Create a simple page layout using <header>, <main>, <footer>.
  2. Add a <nav> inside header with 3 links.
  3. Add a <section> inside main for “About Me”.
