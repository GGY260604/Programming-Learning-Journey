CH09 - Common HTML Attributes

Attributes provide additional information about elements.

Example: <a href="https://google.com">

1) id

This paragraph has an id called "specialText".

Jump to Special Text

2) class

This is highlighted using class.

This is also highlighted.

3) title

Hover your mouse over this text.

4) hidden

This text is hidden.

This text is visible.

5) contenteditable

You can edit this text directly in the browser.

Important Notes

  • id must be unique
  • class can be reused
  • title shows tooltip
  • hidden hides element
  • contenteditable makes element editable
