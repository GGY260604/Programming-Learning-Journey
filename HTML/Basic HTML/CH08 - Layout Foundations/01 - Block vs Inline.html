CH08 - Block vs Inline

HTML elements are generally either block or inline.

Block Elements:

I am a <div> (block). I start on a new line.

I am a <p> (block). I also start on a new line.

I am a <h2> (block). New line again.

Block elements are commonly used to build page sections/structure.

Inline Elements:

This sentence contains <span> (inline) and it stays in the same line.

Here is a link: <a> (inline) still remains in the same line.

You can also make text strong and emphasized without breaking the line.

Inline elements are used to style/mark parts of text inside a block.

Quick Comparison:

  • Block: new line + full width by default
  • Inline: same line + content width only

Common Mistakes:

  • Putting a block element inside an inline element (can cause invalid HTML)
  • Using <br> to force layout instead of learning structure
  • Thinking block/inline is about style only (it affects layout behavior)

Mini Practice:

  1. Add another block element (like <section>) and observe its behavior.
  2. Add 3 inline elements inside a paragraph (span/strong/em) and see they stay on one line.
  3. Try placing a <div> inside a <span> and check what happens (then undo).
