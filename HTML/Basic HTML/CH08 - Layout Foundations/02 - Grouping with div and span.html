CH08 - Grouping with div and span

<div> and <span> are grouping containers. They do not have semantic meaning.

1) div - Block Container

Section 1

This is grouped inside a div container.

Section 2

This is another grouped section.

2) span - Inline Container

This sentence contains highlighted text using span.

You can also make blue text without breaking the line.

Why Are They Important?

  • They help group elements logically
  • They allow applying CSS to specific parts
  • They are foundation for layouts
  • div = block grouping
  • span = inline grouping

Remember: <div> is block-level, <span> is inline.

Common Mistakes

  • Using div when semantic tags are better (like section, article)
  • Putting block elements inside span (invalid HTML)
  • Overusing div unnecessarily

Mini Practice

  1. Create a div container with 3 paragraphs inside.
  2. Use span to color one word in each paragraph.
  3. Try placing a div inside span (observe what happens).
