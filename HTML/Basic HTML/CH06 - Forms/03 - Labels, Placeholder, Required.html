CH06 - Labels, Placeholder, Required

Professional Form Example:

  • <label> improves accessibility
  • for must match input id
  • placeholder shows hint text
  • required forces user to fill input

Why Use Label?

  • Clickable label focuses input
  • Helps screen readers
  • Makes forms accessible

id vs name:

  • id = used for linking label & CSS/JS
  • name = used when sending data to backend

Common Mistakes:

  • Label without for attribute
  • for does not match id
  • Relying only on placeholder without label
  • Missing required when necessary
  1. Add a phone number field.
  2. Add required to all inputs.
  3. Remove label and test accessibility.
  4. Change method to GET and observe URL behavior.
