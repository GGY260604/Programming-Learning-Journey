CH06 - Form Basics

Forms are used to collect user input.

Basic Form Example:

  • <form> = container for form elements
  • action = destination (server URL)
  • method = GET or POST
  • <input> = input field
  • name = key used when sending data

GET vs POST:

GET: Data appears in URL (visible)

POST: Data sent in request body (hidden)

  • Every input should have a name
  • Submit button sends data
  • Forms connect frontend to backend

Common Mistakes:

  • Forgetting name attribute
  • Using GET for sensitive data
  • Missing submit button

Mini Practice:

  1. Add an Email field.
  2. Add an Age field.
  3. Change method to POST.
  4. Observe URL when using GET.
