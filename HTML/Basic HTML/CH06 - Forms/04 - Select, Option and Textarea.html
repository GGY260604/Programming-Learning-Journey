Textarea (Multi-line Input):

  • <select> creates dropdown
  • <option> defines choices
  • multiple allows multiple selections
  • size controls visible options
  • <textarea> allows multi-line text

Important Notes:

  • value attribute is what gets sent to backend
  • First empty option prevents accidental default selection
  • Textarea does NOT use value attribute

Common Mistakes:

  • Forgetting name attribute
  • Not using required for mandatory fields
  • Using textarea for short input
  1. Add 3 more options to the dropdown.
  2. Change size to 5.
  3. Remove required and test form behavior.
