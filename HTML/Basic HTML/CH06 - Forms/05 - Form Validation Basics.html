CH06 - Form Validation Basics

HTML has built-in validation. The browser can block submission if rules are not met.

Try this:

  • Submit without filling required fields.
  • Make username too short (2 chars).
  • Enter email without “@”.
  • Enter studentId like UTM123 (should fail).

Summary:

  • required blocks empty submission
  • minlength / maxlength control text length
  • min / max / step control numbers
  • pattern validates format using regex
  • readonly is submitted, disabled is NOT submitted
  1. Add a phone number input that only allows 10-11 digits using pattern.
  2. Add a password field with minlength 8.
  3. Try changing method to POST (URL won’t show query string).
