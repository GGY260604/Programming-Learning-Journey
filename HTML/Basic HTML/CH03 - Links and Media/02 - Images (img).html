The <img> tag is used to display images. It is a self-closing tag or we call empty tag (no closing tag needed).

Image as Link:

  • src = source (image location)
  • alt = alternative text (accessibility)
  • width/height = control size
  • Relative path = local file
  • Absolute URL = internet image

Common Mistakes:

  • Forgetting alt attribute
  • Wrong file path
  • Image too large (not resizing)
  • Using image for layout instead of CSS
  1. Download an image and place it inside an assets folder.
  2. Display it using relative path.
  3. Resize it to 200px width.
  4. Make the image clickable.
