CH03 - Audio

The <audio> tag is used to embed sound content.

Basic Audio Player:

Common Audio Attributes:

  • controls = show player UI
  • autoplay = auto start (often blocked)
  • loop = repeat audio
  • muted = start muted

Multiple Source Formats:

Common Mistakes:

  • Wrong file path
  • Unsupported audio format
  • Using autoplay without muted (browser blocks it)
  1. Download a small .mp3 file.
  2. Create an assets folder and place it there.
  3. Display it using relative path.
  4. Enable loop and test it.
