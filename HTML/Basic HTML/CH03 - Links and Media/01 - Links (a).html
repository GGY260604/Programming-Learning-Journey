CH03 - Links (Anchor Tag)

The <a> tag creates hyperlinks. Links connect web pages together.

Basic Syntax:

<a href="URL">Link Text</a>

Basic External Link

Go to Google

target="_blank"

Open Wikipedia in New Tab
_blank opens the link in a new browser tab/window.

target="_self"

Open in Same Tab
_self is the default behavior.

target="_parent"

Open in Parent Frame
_parent opens the link in the nearest parent iframe.

target="_top"

Open in Full Browser Window
_top breaks out of ALL iframes and replaces the whole browser window.

Common target Values

Value Meaning
_self Open in current tab/frame
_blank Open in new tab/window
_parent Open in nearest parent frame
_top Break out of all frames
frameName Open inside named iframe

Important Concepts

  • href = destination URL
  • target = where to open the link
  • mailto: = email link
  • tel: = telephone link
  • #id = jump inside same page

Common Mistakes

  • Forgetting href attribute
  • Incorrect file path
  • Forgetting closing </a> tag
  • Misspelling target values
