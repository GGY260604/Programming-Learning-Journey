CH04 - Description List (dl)

A description list is used for terms and their descriptions.

Basic Structure:

HTML
HyperText Markup Language, used to structure web pages.
CSS
Used to style and design web pages.
JavaScript
Used to add interactivity and behavior to websites.
Use <dl> when you have a name + explanation format.

Multiple Descriptions for One Term:

Frontend
Client-side development.
Runs inside the browser.

Practical Example (FAQ style):

What is HTML?
It is the structure of the webpage.
Is HTML a programming language?
No, it is a markup language.

Common Mistakes:

  • Using <dl> just for spacing (wrong purpose)
  • Putting <li> inside <dl> (invalid)
  • Forgetting <dt> before <dd>

Mini Practice:

  1. Create a glossary of 3 programming terms.
  2. Create a mini FAQ using description list.
  3. Add multiple <dd> for one <dt>.
