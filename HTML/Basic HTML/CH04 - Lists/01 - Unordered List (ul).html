CH04 - Unordered List (ul)

An unordered list uses <ul> and each item uses <li>. It shows bullet points by default.

Modern websites usually use CSS instead of the old type attribute.

Comparison:

Method Status
type="square" Old / Legacy HTML
style="list-style-type: square;" Modern CSS Method

Common Mistakes:

  • Putting text directly inside <ul> without <li>
  • Forgetting to close <li> tags
  • Nesting a list outside an <li>
  • Using type on <li> instead of <ul>
