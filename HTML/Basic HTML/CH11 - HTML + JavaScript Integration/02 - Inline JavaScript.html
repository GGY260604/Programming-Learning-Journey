CH11 - Inline JavaScript

Inline JavaScript means writing JS directly inside HTML attributes.

Original Title

How It Works

  • onclick is an event
  • When user clicks, JS runs
  • We can manipulate HTML using JavaScript

Advantages

  • Very simple
  • Quick testing

Disadvantages

  • Mixes HTML and JS
  • Hard to maintain
  • Not scalable
  • Not professional standard

Just like inline CSS, inline JS is NOT recommended for real projects.

Mini Practice

  1. Add a button that changes page background color.
  2. Add another button that shows console.log.
  3. Try changing paragraph text on click.
