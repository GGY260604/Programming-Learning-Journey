CH02 - Headings (h1 to h6)

HTML provides six levels of headings: <h1> (most important) to <h6> (least important).

Important Concept: Hierarchy

Website Title (h1 normally)

Section Title (h2 normally)

Subsection Title (h3 normally)

Why Are Headings Important?

  • They organize content clearly.
  • They improve readability.
  • Search engines use them to understand structure (SEO).
  • Screen readers rely on heading hierarchy.

Common Mistakes:

  • Using multiple <h1> randomly.
  • Skipping levels (like h1 → h4).
  • Using headings just to make text bigger (use CSS later instead).

Mini Practice:

  1. Replace the heading text with your own website title.
  2. Create a proper structure:
    • One h1
    • Two h2
    • One h3 under each h2
  3. Save and observe the visual hierarchy.
