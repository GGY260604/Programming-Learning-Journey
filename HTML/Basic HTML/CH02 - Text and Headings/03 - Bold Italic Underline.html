CH02 - Bold, Italic, Underline

HTML provides multiple ways to format text. Some tags are purely visual, while others have semantic meaning.

Common Mistakes:

  • Using formatting tags just for size (use CSS later)
  • Nesting tags incorrectly (close in reverse order)
  • Overusing underline

Mini Practice:
