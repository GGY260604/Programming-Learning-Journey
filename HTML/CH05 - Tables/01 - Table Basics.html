CH05 - Table Basics

Tables are used to display structured data in rows and columns.

Basic Structure:

Name Age Course
Alex 20 Computer Science
Maria 21 Software Engineering

Common Table Attributes:

  • border = border thickness
  • cellpadding = space INSIDE each cell
  • cellspacing = space BETWEEN cells
  • width = table width
  • align = table alignment
  • bgcolor = background color

border Attribute:

Product Price
Laptop RM3000

cellpadding Attribute:

Name Score
John 95

Larger cellpadding = more space inside cells.

cellspacing Attribute:

Item Quantity
Pen 5

Larger cellspacing = larger gap between cells.

width Attribute:

Country Capital
Malaysia Kuala Lumpur

align Attribute:

Centered Table
This table is centered.

bgcolor Attribute:

Name Grade
Alice A

Cell Attributes:

Width Attribute Background Color
Centered Text Green Cell
  • <table> = container for table
  • <tr> = table row
  • <th> = table header
  • <td> = normal data cell

Important Notes:

  • Header cells are bold and centered by default
  • Each row uses <tr>
  • Tables should store data, NOT webpage layout
  • Many table attributes are old/legacy HTML

Common Mistakes:

  • Forgetting closing tags
  • Uneven number of <td>
  • Using tables for full webpage layout

  2. Add border, cellpadding, and width.
  3. Change table background color.
  4. Center one cell using align.
