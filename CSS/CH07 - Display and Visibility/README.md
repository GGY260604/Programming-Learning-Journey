# CH07 - Display and Visibility

## Chapter Goal

This chapter teaches how CSS controls whether elements behave as block, inline, inline-block, hidden, removed, or special layout boxes.

## Main Idea

The `display` property controls layout behavior. The `visibility` and `opacity` properties control whether an element can be seen without necessarily removing its layout space.
