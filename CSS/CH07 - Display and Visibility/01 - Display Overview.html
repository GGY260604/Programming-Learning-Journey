Display Overview

What does display do?

The display property controls how an element is shown in layout. It affects whether the element creates a new line, stays inline, accepts width and height, or disappears completely.

display: inline

Normal text before inline element normal text after.

display: inline-block

Box 1 Box 2 Box 3

display: none

There is a hidden element below this sentence, but it takes no space.

You cannot see this because display is none.
