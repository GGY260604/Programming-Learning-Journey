# CH06 - Box Model

## Chapter Goal

This chapter teaches the CSS box model: content, width, height, padding, border, margin, border-radius, box-sizing, margin collapse, and outline.

## Main Idea

The box model explains how element size and spacing work in CSS. It is one of the most important foundations for layout design.
