CSS Box Model Overview

Every Element is a Box

CSS treats HTML elements as boxes. The box is made of content, padding, border, and margin.

Visual Box Model Demo

Content Area

The green area is content. The yellow area is padding. The blue line is border. The empty space outside the border is margin. 

.box-model-demo {
  width: 260px;
  height: 100px;
  padding: 30px;
  border: 10px solid #0057d9;
  margin: 30px;
}
