Width and Height

width

This element uses width: 300px;

height

This element uses height: 80px. If there is too much content inside, the content may overflow. This example uses overflow: auto so a scrollbar can appear if needed.

max-width

This element uses max-width: 500px. It can shrink on small screens but will not grow larger than 500px.

min-height

This element uses min-height: 120px. It will be at least 120px tall, but it can grow if content becomes longer.
