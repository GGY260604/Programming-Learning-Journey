Font Family and Fallback

Font Fallback Concept

A font-family list gives the browser several font choices. The first available font will be used. 

.example {
  font-family: Arial, Helvetica, sans-serif;
}

Generic Font Families

Sans-serif example: Arial, Helvetica, sans-serif

Serif example: Georgia, Times New Roman, serif

Monospace example: Courier New, Courier, monospace

Cursive example: Brush Script MT, cursive

Fantasy example: Impact, fantasy

Best Practice

For most websites, use a readable font stack like font-family: Arial, sans-serif;
