@font-face Concept

@font-face {
  font-family: "MyCustomFont";
  src: url("fonts/MyCustomFont.woff2") format("woff2");
}

.example {
  font-family: "MyCustomFont", Arial, sans-serif;
}

This paragraph tries to use "MyCustomFont", then falls back to Arial.

Best Practice

Always include fallback fonts after a custom font: font-family: "CustomFont", Arial, sans-serif;
