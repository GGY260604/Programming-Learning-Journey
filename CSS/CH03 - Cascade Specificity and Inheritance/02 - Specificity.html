CSS Specificity

Specificity Meaning

Specificity is the strength of a CSS selector. If multiple selectors target the same element, the more specific selector usually wins.

Type vs Class vs ID

This paragraph has class="message", so the class selector wins over the type selector.

This paragraph has both class and ID. The ID selector wins. 

p {
  color: blue;
}

.message {
  color: green;
}

#special-message {
  color: red;
}

Combined Selector Specificity

This div has class="notice", but div.notice gives it the final background color.

Simple Specificity Ranking

Inline style is very strong.

#id is stronger than .class.

.class is stronger than element.

element is stronger than universal selector *.
