Inline Style vs Internal Style

Inline Style Has High Priority

This text becomes red because inline style has high priority. 

<p class="inline-test" id="inline-target" style="color: red;">
  This text becomes red.
</p>

Overriding Inline Style with !important

This text becomes purple because .force-color uses !important. 

.force-color {
  color: purple !important;
}

Best Practice

Avoid inline CSS for normal styling. Use classes and external CSS files so your design is easier to maintain.
