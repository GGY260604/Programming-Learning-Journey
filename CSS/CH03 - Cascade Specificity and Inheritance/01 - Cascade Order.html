CSS Cascade Order

What is Cascade?

Cascade means CSS can have many rules targeting the same element, and the browser decides which rule should apply.

When two selectors have the same strength, the later rule usually wins.

Same Selector Example

This text becomes red because the later CSS rule wins. 

.same-selector {
  color: blue;
}

.same-selector {
  color: red;
}

Background Override Example

This box first receives light blue background, then it is overridden by light red background.

Simple Rule

If two CSS rules have the same specificity, the rule written later is applied.

Important idea: later rule + same specificity = later rule wins
