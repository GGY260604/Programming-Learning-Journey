CSS Inheritance

Inherited Properties

Parent element has dark blue text and Georgia font.
Child element inherits text color and font family. 
.parent {
  color: darkblue;
  font-family: Georgia, serif;
}

Non-Inherited Properties

Parent has a red border.
Child does not inherit the parent's border automatically.

Forcing Inheritance

Parent has a red border.
Child uses border: inherit;, so it copies the parent's border.

Common Inherited Properties

Text-related properties are commonly inherited, such as:

color, font-family, font-size, line-height, text-align

Box-related properties usually are not inherited, such as:

margin, padding, border, background-color, width
