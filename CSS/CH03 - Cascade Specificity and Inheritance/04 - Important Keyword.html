CSS !important Keyword

Normal Cascade

This text becomes green because the later rule wins. 

.normal-rule {
  color: blue;
}

.normal-rule {
  color: green;
}

Using !important

This text becomes purple because !important overrides the normal ID rule. 

.important-demo {
  color: purple !important;
}

#important-target {
  color: red;
}

Why Use Carefully?

This alert text stays red because color: red uses !important.

Too many !important rules make CSS difficult to control.
