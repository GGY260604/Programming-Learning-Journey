initial, inherit, unset and revert

initial

Parent has dark blue text.

This child uses color: initial, so it does not stay dark blue. 

.use-initial {
  color: initial;
}

inherit

Parent has a border.

This child uses border: inherit. 

.use-inherit {
  border: inherit;
}

unset

Parent has dark blue text and border.

This child uses color: unset. Since color is inherited, it keeps parent color.

This child uses border: unset. Since border is not inherited, it removes the border.

revert

The first button uses custom CSS. The second button uses all: revert to return closer to browser default styling. 

.revert-button {
  all: revert;
}
