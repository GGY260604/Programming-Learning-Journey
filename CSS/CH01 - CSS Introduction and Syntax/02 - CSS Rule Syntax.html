CSS Rule Syntax

Basic Pattern

selector {
  property: value;
}

A CSS rule selects an HTML element and applies visual styles to it.

Working Example

This text is styled using a CSS rule. 

.demo-text {
  color: purple;
  font-size: 22px;
  font-weight: bold;
  background-color: #f0e6ff;
  padding: 10px;
}

Important Terms

.demo-text is the selector.

color, font-size, and padding are properties.

purple, 22px, and 10px are values.

: connects a property to its value.

; ends one declaration.
