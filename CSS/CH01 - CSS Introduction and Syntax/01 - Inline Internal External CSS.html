CSS Applying Methods

CSS can be applied using inline CSS, internal CSS, or external CSS. In real projects, external CSS is usually preferred because it keeps HTML and CSS cleaner.

1. Inline CSS

This paragraph uses inline CSS.

Code idea: <p style="color: red;">

2. Internal CSS

This paragraph uses internal CSS.

Internal CSS is useful when one page has its own special styling.
