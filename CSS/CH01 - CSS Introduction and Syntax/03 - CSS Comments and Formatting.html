CSS Comments and Formatting

CSS Comment Syntax

/*
  This is a CSS comment.
  It will not appear on the webpage.
*/

Comments are mainly for developers, not for users.

Recommended Formatting

This paragraph uses readable CSS formatting. 

.good-format {
  color: green;
  font-size: 20px;
  font-weight: bold;
}

Compact Formatting

This also works, but the CSS rule is harder to read. 

.compact-format { color: brown; font-size: 20px; font-weight: bold; }
