CSS Color Values

Different Ways to Write Colors

Color name: red
HEX: #0000FF
RGB: rgb(0, 128, 0)
RGBA: rgba(255, 165, 0, 0.45)
HSL: hsl(280, 80%, 40%)
HSLA: hsla(180, 80%, 50%, 0.4)

When to Use Which?

Color name is simple, but limited.

HEX is very common in web design.

RGB is useful when working with red, green, and blue values.

RGBA is useful when you need transparency.

HSL is easier when adjusting hue, saturation, or brightness.
