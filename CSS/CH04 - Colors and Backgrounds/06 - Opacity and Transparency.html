Opacity and Transparency

opacity vs RGBA

opacity: 0.45;
Text also becomes transparent.
background-color: rgba(0, 87, 217, 0.45);
Text stays clear.
background-color: transparent;

Important Difference

Use opacity when you want the whole element to be transparent.

Use rgba() or hsla() when you only want the background color to be transparent. 

.opacity-demo {
  opacity: 0.45;
}

.rgba-demo {
  background-color: rgba(0, 87, 217, 0.45);
}
