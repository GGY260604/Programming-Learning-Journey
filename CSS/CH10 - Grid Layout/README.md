# CH10 - Grid Layout

## Chapter Goal

This chapter teaches CSS Grid layout using executable HTML examples. It covers grid containers, columns, rows, repeat, minmax, auto-fit, gap, item placement, named grid areas, alignment, and common grid patterns.

## Main Idea

CSS Grid is best for two-dimensional layout. It controls rows and columns at the same time, making it powerful for page layouts, dashboards, galleries, and responsive card systems.
