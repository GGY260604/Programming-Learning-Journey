# CH09 - Flexbox Layout

## Chapter Goal

This chapter teaches Flexbox layout using executable HTML files. It covers flex containers, flex items, direction, alignment, wrapping, gap, flexible sizing, item order, and common UI patterns.

## Main Idea

Flexbox is best for one-dimensional layouts. It is very useful when arranging elements in a row or column, especially when alignment and spacing are important.
