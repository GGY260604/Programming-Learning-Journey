CSS Position Overview

What does position do?

The position property controls how an element is placed in the page. It also decides whether top, right, bottom, and left can move the element.

static vs relative

position: static; top and left do not move me.
position: relative; top and left move me visually.
Normal item after the relative element.

Notice that the relative element moves visually, but the page still keeps its original space. 

.relative-demo {
  position: relative;
  top: 20px;
  left: 30px;
}
