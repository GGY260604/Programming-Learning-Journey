08 - Method Property and Value Reference

Concept

This file summarizes the most important values passed into AJAX methods. It is useful as a quick reference after finishing the practical examples.

XMLHttpRequest Reference

Syntax Meaning
new XMLHttpRequest() Create the AJAX request object.
open(method, url, async) Prepare the request.
send(body) Send the request. The body is optional for GET.
setRequestHeader(name, value) Set request metadata, such as Content-Type.
readyState Request stage from 0 to 4.
status HTTP result code, such as 200 or 404.
responseText Response body as text.
