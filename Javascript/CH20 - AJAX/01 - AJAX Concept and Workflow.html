CH20 - AJAX

01 - AJAX Concept and Workflow

Concept

AJAX means Asynchronous JavaScript and XML. It allows JavaScript to communicate with a server and update part of a page without refreshing the whole page.

Although the name contains XML, modern AJAX can work with text, JSON, XML, and other response types.

Basic Workflow

  1. User performs an action, such as clicking a button.
  2. JavaScript creates a request object.
  3. The request is sent to a URL.
  4. The server or file returns data.
  5. JavaScript uses the response to update the page.
