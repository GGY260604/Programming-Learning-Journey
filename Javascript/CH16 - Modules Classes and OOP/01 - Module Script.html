Concept

JavaScript modules allow one JavaScript file to reuse values from another JavaScript file.

This page loads 01 - main.js as a module. Then 01 - main.js imports functions from 01 - math.js.

If the result does not appear, open this folder using a local server. Module imports may not work correctly when the file is opened directly using file://.
