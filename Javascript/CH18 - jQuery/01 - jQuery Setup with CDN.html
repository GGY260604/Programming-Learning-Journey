CH18 - jQuery

01 - jQuery Setup with CDN

Concept

jQuery is a JavaScript library. It gives a shorter syntax for selecting elements, changing HTML/CSS, handling events, creating animations, and making AJAX requests.

This chapter uses the CDN script below in every file: 

<script src="https://code.jquery.com/jquery-4.0.0.min.js"></script>

In jQuery, $ is a shortcut for jQuery. For example, $("p") means select all paragraph elements.
