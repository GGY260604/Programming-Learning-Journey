CH18 - jQuery

16 - Method Argument Patterns

Concept

jQuery methods often follow repeated argument patterns. Once you understand the pattern, many methods become easier to learn.

Common jQuery Argument Patterns

Pattern Example Meaning
Selector string $(".card") Select elements that match the CSS/jQuery selector.
Getter $("#name").val() No value is passed, so the method reads a value.
Setter $("#name").val("Galen") A value is passed, so the method changes a value.
Object setter $("#box").css({ width: "200px" }) An object is passed to set multiple values at once.
Callback setter .text(function (index, oldText) { ... }) A function computes the new value for each matched element.
Event handler .on("click", function (event) { ... }) A function runs when the event happens.
Delegated event .on("click", "li", function () { ... }) The parent listens for events from matching child elements.
AJAX options object $.ajax({ url, method, data }) An object configures the request.
