# CH06 - Functions

This chapter teaches JavaScript functions using runnable HTML examples.

Functions are important because they allow code to be reused, organized, and passed around as values.

## Files in this chapter

| File | Main focus | Key syntax / concept |
|---|---|---|
| 01 - Function Declaration.html | Create named reusable functions | `function name() { ... }` |
| 02 - Function Expression.html | Store a function inside a variable | `const name = function() { ... };` |
| 03 - Arrow Function.html | Write shorter function expressions | `const name = () => { ... };` |
| 04 - Parameters Arguments and Default Values.html | Pass values into functions | parameters, arguments, default parameters |
| 05 - Rest Parameters.html | Accept many arguments | `...items` |
| 06 - Return Values.html | Send results back from a function | `return` |
| 07 - Callback Function.html | Pass a function into another function | callback function |
| 08 - IIFE.html | Run a function immediately | `(function() { ... })();` |
| 09 - Closure.html | Let inner functions remember outer variables | closure, private data |

## Suggested learning order

Study the files in numeric order. Function declaration and function expression should be learned before arrow function, callback, IIFE, and closure.

## Important notes

- Use function declaration when you want a clear named reusable function.
- Use function expression when you want to store a function as a value.
- Use arrow function for short functions and callbacks.
- Use parameters to make a function flexible.
- Use `return` when the function should give a result back.
- A callback is a function passed into another function.
- A closure allows a function to remember variables from its outer scope.
