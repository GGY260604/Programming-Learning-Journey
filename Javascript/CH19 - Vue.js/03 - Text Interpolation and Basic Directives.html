CH19 - Vue.js

03 - Text Interpolation and Basic Directives

Concept

Vue uses template syntax to connect JavaScript data with HTML. The most common syntax is text interpolation using {{ }}.

Text Interpolation

Normal interpolation: {{ message }}

Expression inside interpolation: {{ firstName + " " + lastName }}

Calculation inside interpolation: {{ price * quantity }}

Basic Directives

v-html output:

v-once value: {{ message }}

v-pre keeps this unchanged: {{ message }}
