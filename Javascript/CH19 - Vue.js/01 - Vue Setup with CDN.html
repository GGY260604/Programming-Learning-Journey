01 - Vue Setup with CDN

Concept

Vue can be used directly in a normal HTML file by loading it from a CDN. After Vue is loaded, the global object Vue becomes available.

The most basic Vue flow is:

  1. Load Vue using a <script> tag.
  2. Create an app using Vue.createApp().
  3. Mount the app using .mount("#app").
