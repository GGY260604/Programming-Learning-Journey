# CH01 – Create First Flutter App

## Create project
Go to the folder you want your project to be created in:

flutter create my_first_flutter_app

## Enter project
cd my_first_flutter_app

## Run (choose one)
flutter run
flutter run -d chrome
flutter run -d windows

## Notes
- Flutter projects are already runnable after creation.
- We'll replace lib/main.dart with our note-style version.
