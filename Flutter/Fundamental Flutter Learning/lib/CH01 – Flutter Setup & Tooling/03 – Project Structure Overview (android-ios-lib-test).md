# CH01 – Flutter Project Structure Overview

## Most important folder for beginners
lib/
- Your Dart + Flutter UI code lives here
- main.dart is the entry point

## Other common folders
android/  -> Android native config (usually don't touch early)
ios/      -> iOS native config (usually don't touch early)
test/     -> testing files
pubspec.yaml -> dependencies + assets + fonts

## Beginner rule:
✅ Focus on lib/ and pubspec.yaml first.
