# Next.js Architecture Learning

This repository is used to learn and explore the **basic architecture of a Next.js project**.

The purpose of this project is to understand how a Next.js application is structured, including how different parts of the framework work together, such as:

- App Router structure
- File-based routing
- Page and layout organization
- API routes using `route.ts`
- Interaction between frontend pages and backend endpoints

The repository focuses on understanding the **core project structure and architecture** of Next.js rather than building a full production application.
